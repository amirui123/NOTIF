# مرور دمو و موتور — وضعیت فعلی

مرور کد `IslandX-Prototype/index.html` (v7) + تست واقعی مدل متن با Node.

## ۱) چی داریم

**رابط**
- ۱۶ حالت: `idle`, `peek` (hover panel), `music`, `musicx`, `glance`, `toast`, `reply`, `shot`, `prev`, `vol`, `bri`, `chg`, `lowbat`, `timerc`, `timerx`, `event`, `priv` + حالت `line` برای تمام‌صفحه — یعنی همه‌ی ۱۶ حالتِ رفرنس پوشش داده شده.
- مورف با **فنر مستقل برای هر ویژگی** (w/h/r/scale، انتگرال‌گیر نیمه‌ضمنی با گام ۴ms). فنر سرعتش را هنگام تغییر هدف نگه می‌دارد، پس انتقال‌های قطع‌شده نمی‌پرند.
- ضربه‌ی squash-and-stretch کوچک هنگام باز/بسته شدن، `prefers-reduced-motion` هم رعایت می‌شود.
- **Hover intent تطبیقی**: در حالت عادی ۷۰ms، در تمام‌صفحه باید کرسر روی خط «توقف» کند (پیش‌فرض ۴۵۰ms). اگر تصادفی باز شود زمان را ۱.۳ برابر می‌کند و اگر عمدی باز شود ۰.۹۲ برابر — و در `localStorage` ذخیره می‌شود.
- انیمیشن‌ها فقط تا وقتی فنر در حال حرکت است rAF می‌گیرند؛ ویژوالایزر هم فقط وقتی حالت موزیک دیده می‌شود. (هم‌راستا با بادجت پرفورمنسِ فاز ۱.)

**مدل داخل دمو**
- مدل متن: fastText-style با n-gram هش‌شده (۸۱۹۲ سبد، ۲۴ بعد) → P(unwanted) + ۴ کلاس نوع.
- سه شبکه‌ی رفتاری (ensemble) روی ۳۱ ویژگی: زمان، اپ، فرستنده، سابقه‌ی واکنش، حالت busy، خروجی مدل متن و …
- حافظه‌ی روی‌دستگاه: به‌ازای هر (فرستنده، اپ، بلوک ۶ ساعته، busy) آمار n/e/r نگه می‌دارد و `localStorage` می‌شود.
- سیاست تصمیم: `show` / `glance` / `silent` / `scam` بر اساس سود انتظاری با هزینه‌ی وابسته به context + گاردهای «کد ورود همیشه نشان داده شود» و «کلاهبرداری هرگز promote نشود».

**بقیه**
- ویژوالایزر: ۴ سبک (`bars`, `ribbon`, `scope`, `dots`) که از bpm ترک ساخته می‌شود، نه صدای واقعی.
- Battery brain واقعی‌نما (۶۰Wh، وات شارژر → متن حالت)، تایمر پومودورو، اسلایدرهای ولم/روشنایی.
- داک شبیه‌ساز (اعلان / context / رویداد سیستم) + پنل «What the island has learned» + خط لاگ.

### دو یافته‌ی مهم

**۱. گارد کلاهبرداری فقط انگلیسی را می‌گیرد.** — ✅ **رفع شد** (پایین را ببینید) در `decide()` شرط `tm.pt[3] > .5` است، یعنی فقط وقتی *کلاس نوع* = scam باشد. فیشینگ فارسی («کد ملی و شماره کارت بفرست») و فینگلیش به‌درستی «مزاحم» تشخیص داده می‌شوند (pu≈۱۰۰٪) اما برچسبشان promotional است، پس هیچ ⚠ نمی‌گیرند و به‌عنوان توست تبلیغاتی نشان داده می‌شوند. این همان چیزی است که باید بدانیم: کاربر پیام کلاهبرداری می‌بیند بدون هشدار.
**رفع:** تابع `scamScore()` اضافه شد؛ گارد حالا چندسیگنالی است و امتیاز ۰..۱ می‌سازد:

| سیگنال | وزن |
|---|---|
| کلاس متن = scam | +۰.۵۵ |
| درخواست مدرک (کد ملی / شماره کارت / CVV / رمز / password) | +۰.۴۵ |
| طعمه‌ی جایزه (برنده / جایزه / gift card / barande / jayze) | +۰.۳۰ |
| لینک / دامنه | +۰.۲۰ |
| فعل اقدام (کلیک کنید / ارسال کنید / click here) | +۰.۲۰ |
| فوریت (مسدود / تعلیق / urgent) | +۰.۱۲ |
| مبلغ | +۰.۱۰ |
| مدرک + جایزه با هم | +۰.۱۵ |
| `P(unwanted) > 0.9` | +۰.۱۵ |

`score ≥ 0.6` **و** وجود حداقل یک شاهد محتوایی (مدرک / لایه‌ی جایزه / لینک) **و** فرستنده ناشناس ⇒ کلاس `scam`.
شرط «شاهد محتوایی» جلوی مثبت کاذب روی ایمیل فوری واقعی را می‌گیرد: مدل متن جمله‌ی «Urgent: need the report» را scam می‌بیند (۰.۸۲) ولی چون هیچ مدرک/جایزه/لینکی ندارد، فلگ نمی‌شود. فرستنده‌ی مورد اعتماد (مخاطب یا کسی که قبلاً جوابش را داده‌اید) هرگز فلگ نمی‌شود.
نتیجه: **۱۲ از ۱۲ کیس سیاست** درست شد، از جمله دو کیسی که قبلاً رد می‌شد. دلیل تصمیم هم در پنل لاگ چاپ می‌شود (`scam guard: cred · prize · cred+prize`).

**۲. احتمالات اشباع‌اند (۰.۰٪ و ۱۰۰.۰٪).** مدل رفتاری از دمای `WB.T` رد می‌شود ولی مدل متن هیچ کالیبراسیونی ندارد، پس خروجی‌اش عملاً دودویی است. برای رابطی که «اهمیت ۰–۱۰۰٪» نشان می‌دهد این یعنی نوار اهمیت پرش‌های ۹۹٪ دارد و کاربر معنی «۷۳٪» را نمی‌فهمد. README مدل هم temperature scaling (Guo et al. 2017) را جزو ایده‌ها آورده — برای مدل متن اعمال نشده.

## ۳) کمبودهای رابط

| موضوع | وضعیت |
|---|---|
| RTL / بومی‌سازی | UI تماماً انگلیسی است؛ وزیرمتن فقط برای بدنه‌ی پیام‌ها استفاده می‌شود. `lang` ست نشده. |
| دسترس‌پذیری | صفر `aria-*`، صفر `tabindex`؛ باز شدن پنل فقط با hover (کلیک/تاچ کار نمی‌کند) و فوکوس کیبورد ندارد. |
| امنیت محتوا | ✅ رفع شد: تابع `esc()` اضافه شد و متن پیام‌ها در پنل hover قبل از `innerHTML` اسکیپ می‌شود. |
| صداقت دمو | موزیک، باتری و تایمر شبیه‌سازی‌اند و هیچ‌جا در UI برچسب «simulated» ندارند؛ فقط در کامنت کد توضیح داده شده. |
| کد مرده | ✅ `level()` حذف شد؛ `ctx` ذخیره نمی‌شود (با رفرش می‌پرد) ولی حافظه و dwell ذخیره می‌شوند — هنوز ناهماهنگ. |
| reset | فقط حافظه را پاک می‌کند، dwell و ctx را نه. |

## ۴) سه مسیر پیشنهادی

1. **درست کردن گارد کلاهبرداری** (کم‌ریسک، اثر بالا): تست بالا را به ۹/۹ برسانیم، ولی این بار با منطق سیاست نه دست‌کاری وزن‌ها.
2. **فارسی‌سازی + RTL + دسترس‌پذیری**: چون محصول برای کاربر ایرانی است، UI انگلیسی در دمو معنی ندارد.
3. **کالیبراسیون مدل متن** و بازتولید `metrics_text.json` با خروجی دمایی، تا نوار اهمیت واقعاً معنی داشته باشد.
